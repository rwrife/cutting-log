# Privacy and permissions

Cutting Log has no account, analytics, advertising, tracking, or network service.

- Camera permission is requested only after **Use camera**.
- The system Photos picker grants access only to the selected item and does not require broad photo-library permission.
- Notification permission is requested only when saving the first check-in. Check-ins remain usable in the app when permission is denied.

Photos, notes, and backups may be sensitive. They remain in app-controlled storage unless the user explicitly shares an export.
