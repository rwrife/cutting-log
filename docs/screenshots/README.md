# Native iPhone screenshots

Captured from the running SwiftUI app on a 6.5-inch iPhone 11 Pro Max simulator
(iOS 26.5) on September 19, 2026, using Xcode 26.6. All four PNGs are native
1242 × 2688 portrait captures, without resizing. The sample journal was entered
through the app, verified across termination and relaunch, and copied into a
clean 6.5-inch simulator for these captures.

- `01-private-journal.png`: journal overview after relaunch.
- `02-find-active-cuttings.png`: parent plant, active cutting, and sibling summary.
- `03-capture-details.png`: populated new-cutting form before saving.
- `04-connected-lineage.png`: saved cutting details and initial timeline observation.

These replace the screenshots of the previous Flutter interface.
