# Screenshot evidence guidance

Only attach screenshots captured from built Cutting Log binaries (debug/release/simulator/device), never from mockups.

For each screenshot include:

- commit SHA,
- platform and OS version,
- screen description,
- whether it was captured on emulator/simulator or physical device.

Minimum screenshot set for release candidate:

1. Home screen with offline/account-free messaging.
2. Parent and cutting creation flow.
3. Timeline with stage + observation entries.
4. Reminder creation and due-state review.
5. Photo attachment in timeline.
6. Export and restore preview screens.
7. Settings/privacy/erase surface.
8. Accessibility screenshots at larger text scale.

Store screenshots outside the repository by default unless the maintainers explicitly choose to commit them.
